# AI Customer Review Analyzer

A Python project that uses artificial intelligence to analyze customer reviews, classify sentiment, identify common themes, and summarize customer feedback.

## Features

- Uses a Hugging Face sentiment analysis model
- Classifies reviews as positive or negative
- Displays AI confidence scores
- Detects common review themes such as:
  - Battery
  - Customer service
  - Product quality
  - Recommendations
- Generates a summary of sentiment totals
- Shows the most frequently discussed themes

## Technologies Used

- Python
- Hugging Face Transformers
- Natural Language Processing (NLP)
- AI / Machine Learning

## Example

The program analyzes reviews such as:

> "The bike was amazing and the battery lasted all day!"

It then produces information such as:

- Sentiment: POSITIVE
- Confidence: 99%+
- Theme: Battery

## Why I Built This

I built this project to practice applying AI and natural language processing to a real-world business problem. Customer reviews contain valuable information, and this project demonstrates how AI can help automatically organize and summarize that feedback.
